Records and gates a human decision about an agent skill before it is allowed to load. Local, dependency-free, and it never edits what it inspects.

Status

Nothing is published yet

There is no npm package and no release, so npx pratiq does not run. Everything below is the 0.1.0 surface, not an installation instruction. It works today from a checkout, against a library holding no copy of the tool.

Saying so here rather than after you have tried it is the same rule the tool applies to itself: a stage without a verb is listed as a stage without a verb, and deleting the row to make the list look complete is precisely the move pratiq exists to refuse.

The name

One yellow flag, two opposite meanings

Free pratique is the clearance a ship is granted after inspection — entered in its papers, without which nobody boards and nobody disembarks. A vessel requesting it flies signal flag Q: a plain yellow rectangle with nothing on it. It is pronounced prah-teek, and yes, you have to be told that.

Then

The yellow jack marked a vessel that was, or might be, harbouring disease. Yellow marked infected houses before it ever went to sea. Keep away — this has not been looked at.

Now

Under the modern code, Q flown alone reads “my vessel is healthy, I request free pratique.” Come aboard and check. The flag comes down only when a human has granted clearance.

Which is the tool

A skill in quarantine and a skill cleared into the library are the same bytes under the same flag. Only a recorded human decision separates them.

The claim

It is not a scanner

Scanners exist. Cisco, NVIDIA, Socket, Snyk and VirusTotal all ship one, along with eight open-source projects, and every one of them has been bypassed on record. pratiq has a scanner inside it, and that is not the claim.

The claim is that a human decision is recorded against specific bytes, and a gate enforces that decision without being able to be argued with. Nothing is adopted because an agent concluded it looked fine. Put plainly: before a skill you downloaded from a stranger runs inside your agent, someone has to have actually read it.

The lifecycle

Every stage is real, including the two without a verb

A stage without a command is a thing you do by hand, not a thing that does not exist. Both are marked.

intake fetch from a link at a pinned commit, without reading it, into quarantine pratiq intake
audit scan every file as data; a human adjudicates every finding; report only, never edit pratiq audit
adopt / decline the human decides. A declined skill keeps a permanent row, so it is never re-audited from nothing by hand · adopt in 0.2
promote re-scan and move it into the library — or refuse pratiq promote
ledger one machine-written record per held skill: origin, hashes, verdict, contract, install, usage pratiq ledger
refresh re-diff the pinned commit against upstream; report drift, never move the pin pratiq refresh
usage count what actually fired, from local transcripts, reading no message text pratiq usage
view the graph, served locally against any skill library from a checkout · view in 0.2

Principles

What it refuses to do

Fetch blind

Never read what you fetch. An agent that has read the payload before the payload was scanned has already lost, and no later gate recovers it.

The record makes the decision checkable

By someone who was not there. That is what a record is for, and it is why the verdict is tied to specific bytes rather than to a name or a version.

The gate cannot be reasoned with

It is a script, not a sentence in a prompt, because the material being processed is untrusted text written to be read as instructions.

Declining is a success

A refused skill with a written reason is a finished piece of work, not a failure. It keeps its row.

Nothing leaves the machine

Two commands reach the network — intake and refresh — and both only to a source you already named. Usage counting reads local transcripts and never message text.

The contracts that do not move

Three exit codes, and the difference between them matters

A script consuming these has to tell 1 and 2 apart. Collapsing them is how a CI gate starts lying about which problem it found.
